# Media inspection workflow

1. Record duration, resolution and sampling strategy.
2. Sample beginning, middle, end and every major state change.
3. Separate confirmed observation, probable inference and unknown.
4. Never derive exact dimensions from perspective alone.
5. Inspect construction, fastening, load points, finish, interior and scale references.
6. Recommend physical tests for structural claims.
7. Keep audio claims separate unless audio transcription was explicitly analyzed.
