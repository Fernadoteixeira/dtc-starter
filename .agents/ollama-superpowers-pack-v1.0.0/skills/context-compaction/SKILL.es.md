# Comprimir contexto con procedencia

## Workflow

1. Define objetivo, alcance, restricciones y evidencia de finalización.
2. Inspecciona el conjunto mínimo capaz de refutar la hipótesis actual.
3. Produce un plan reversible con gates explícitos.
4. Ejecuta solo acciones aprobadas y registra evidencias.
5. Valida resultados, distingue regresiones y emite GREEN, YELLOW o RED.

## Required output

- Scope and assumptions
- Evidence inspected
- Decision or patch plan
- Validation results
- Remaining risks
- Final gate
