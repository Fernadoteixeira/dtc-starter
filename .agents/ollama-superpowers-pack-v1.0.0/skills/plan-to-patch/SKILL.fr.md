# Implémenter un correctif minimal

## Workflow

1. Définissez objectif, périmètre, contraintes et preuve d'achèvement.
2. Inspectez le plus petit ensemble capable de réfuter l'hypothèse.
3. Produisez un plan réversible avec gates explicites.
4. Exécutez uniquement les actions approuvées et consignez les preuves.
5. Validez les résultats, distinguez les régressions et rendez GREEN, YELLOW ou RED.

## Required output

- Scope and assumptions
- Evidence inspected
- Decision or patch plan
- Validation results
- Remaining risks
- Final gate
