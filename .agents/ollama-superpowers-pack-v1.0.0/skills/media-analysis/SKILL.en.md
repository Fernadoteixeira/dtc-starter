# Analyze images and videos with confidence

## Workflow

1. Define objective, scope, constraints and completion evidence.
2. Inspect the smallest set able to falsify the current hypothesis.
3. Produce a reversible plan with explicit gates.
4. Execute approved actions only and record evidence.
5. Validate outcomes, distinguish regressions and issue GREEN, YELLOW or RED.

## Required output

- Scope and assumptions
- Evidence inspected
- Decision or patch plan
- Validation results
- Remaining risks
- Final gate
