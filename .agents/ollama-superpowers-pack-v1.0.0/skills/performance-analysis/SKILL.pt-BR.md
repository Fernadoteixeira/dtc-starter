# Medir e otimizar desempenho

## Workflow

1. Defina objetivo, escopo, restrições e evidência de conclusão.
2. Inspecione o menor conjunto capaz de refutar a hipótese atual.
3. Produza plano reversível com gates explícitos.
4. Execute somente ações aprovadas e registre evidências.
5. Valide resultados, diferencie regressões e emita GREEN, YELLOW ou RED.

## Required output

- Scope and assumptions
- Evidence inspected
- Decision or patch plan
- Validation results
- Remaining risks
- Final gate
