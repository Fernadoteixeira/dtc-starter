## 1. Resumo

## 13. Princípios Aplicados ao PRD

| Princípio inegociável | Aplicação no PRD |
|---|---|
| Não usar escassez falsa | FR-14 (disponibilidade real), FR-18 (lista de espera só para esgotado real), FR-80 (drop com produção limitada real) |
| Não vender abaixo do custo | PR-05/FR-35 (cupom nunca abaixo do custo), CR-04 (página de transparência) |
| Não usar dark patterns | NFR (sem countdown, sem confirm-shaming, sem opt-in pré-selecionado), FR-36 (checkout como convidado) |
| Autoria estrutural | FR-12 (artista na PDP), FR-90/91 (entidade e página de artista), CR-10 (embalagem com nome) |
| Tempo é real | FR-14 (disponibilidade honesta), CR-06 (política de envio com prazos reais) |
