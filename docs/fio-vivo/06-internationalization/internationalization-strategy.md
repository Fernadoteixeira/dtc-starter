## 1. Princípios

| # | Princípio |
|---|---|
| 1 | Não traduzir e lançar todos os mercados simultaneamente |
| 2 | Cada mercado exige avaliação de viabilidade com evidência |
| 3 | Preço internacional ≠ conversão direta de câmbio |

## 2. International Market Viability Score (IMVS)

### 2.1 Fórmula

```
IMVS =
  0.20 × Demanda Potencial
+ 0.15 × Adequação de Preço
+ 0.15 × Viabilidade Logística
+ 0.10 × Margem Líquida
+ 0.10 × Facilidade de Pagamento
+ 0.10 × Afinidade Cultural
+ 0.10 × Facilidade Regulatória
+ 0.05 × Capacidade de Atendimento
+ 0.05 × Potencial Orgânico
```

### 2.2 Classificação

| Score | Classificação | Ação |
|---|---|---|
| 80-100 | Piloto prioritário | Lançar primeiro |
| 65-79 | Piloto controlado | Preparar, lançar após prioritário |
| 50-64 | Observar e preparar | Pesquisa, não lançar |
| <50 | Não priorizar | Ignorar por ora |

## 4. Preço internacional

### 4.1 Fórmula

```
Preço Internacional Final =
  Preço sustentável local (BRL → moeda alvo via câmbio com buffer)
  + embalagem de exportação
  + frete ou subsídio
  + seguro
  + imposto (IVA/VAT/GST)
  + duty (se aplicável)
  + custo financeiro
  + risco de devolução
  + custo de atendimento
  + custo de localização
  + margem de canal
  + buffer cambial controlado (5-8%)
```

### 4.2 Depois

```
Preço Exibido =
  Arredondamento psicológico local
  + posicionamento de marca
  + coerência com mercado
  + transparência tributária (DDP vs DDU)
```

### 4.3 Regras

| Regra | Descrição |
|---|---|
| Snapshot cambial | Salvar taxa de câmbio no momento do cálculo |
| Bandas cambiais | Recalcular somente ao ultrapassar ±5% |
| Validade do preço | 24h para cotação; 7d para price list |
| Tributos inclusos | Informar se DDP (impostos inclusos) ou DDU |
| Prazo realista | Não prometer frete internacional sem simulação |
| Buffer cambial | 5-8% para absorver volatilidade BRL |

### 4.4 Exemplo conceitual — Duna Terracota para Portugal

| Item | Valor (estimativa) |
|---|---|
| Preço recomendado BRL | R$ 790 |
| Câmbio BRL→EUR (com buffer 7%) | € 140 |
| Embalagem exportação | € 8 |
| Frete BR→PT | € 25 |
| Seguro | € 3 |
| IVA PT (23%) | € 38 |
| Custo financeiro | € 4 |
| Risco devolução | € 5 |
| Atendimento | € 3 |
| Margem canal | — (DTC) |
| **Total (DDP)** | € 226 |
| Arredondamento psicológico | € 229 |
| **Preço exibido PT** | **€ 229** |

> ⚠️ Estimativa conceitual. Custo real de frete, duty e IVA devem ser confirmados com provider logístico.

## 6. Localização técnica

### 6.1 Presentation locale vs commercial region

| Conceito | Implementação | Exemplo |
|---|---|---|
| Presentation locale | Idioma da UI | pt-BR, en-US, es-ES, fr-FR |
| Commercial region | Região Medusa (moeda, frete, imposto) | BR (BRL), US (USD), EU (EUR) |
| Country code | Rota `[countryCode]` | /br, /us, /pt, /fr |

> ⚠️ **Regra do usuário:** tratar presentation locale separadamente de commercial country/region e currency. Um usuário em /us pode querer ver pt-BR (locale) mas comprar em USD (region).

### 6.2 Tradução de conteúdo

| Tipo | Abordagem |
|---|---|
| UI strings | next-intl ou equivalente, catálogos por locale |
| Produto (title, description) | Metadata por locale no Medusa |
| Coleções | Nome por locale |
| E-mails | Templates por locale |
| FAQ/Ajuda | Conteúdo por locale |
| Legal | Por jurisdição (LGPD BR, GDPR UE) |

## 7. Gates de viabilidade internacional

| Gate | Critério | Evidência |
|---|---|---|
| G-INT-0 | Descoberta concluída | Discovery docs aprovados |
| G-INT-1 | Mercado base (BR) operando | ≥30 PSEEP/mês por 3 meses |
| G-INT-2 | IMVS calculado para mercado alvo | Score ≥ 65 para piloto |
| G-INT-3 | Logística validada | Cotação real de frete + prazo |
| G-INT-4 | Pagamento configurado | Stripe/PayPal no mercado alvo |
| G-INT-5 | Tradução completa | UI + conteúdo do produto |
| G-INT-6 | Compliance | GDPR (UE), LGPD (BR), tax registration |
| G-INT-7 | Atendimento | Suporte no idioma (ou fallback claro) |
| G-INT-8 | Price list local | Preços calculados via fórmula internacional |
| G-INT-9 | Soft launch | 10 pedidos em 30d sem incidentes |
| G-INT-10 | Full launch | 50+ pedidos em 90d com NPS ≥ 40 |
